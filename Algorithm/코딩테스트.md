# 자바 코딩테스트 벼락치기 정리

## 1단계: 입출력 + 기본 문법

### 코드 골격
- 백준/기업 코테: `public class Solution { public static void main(String[] args) throws IOException { ... } }`
- 프로그래머스: `class Solution { public int solution(int[] arr) {...} }` — main 불필요

### Scanner
- `nextInt()`: 공백 기준 정수 하나 읽기
- `nextLong()`: 공백 기준 long 하나 읽기
- `nextDouble()`: 공백 기준 실수 하나 읽기
- `next()`: 공백 기준 문자열(단어) 하나 읽기
- `nextLine()`: 공백 포함, 줄바꿈 전까지 한 줄 읽기
- `hasNext()` / `hasNextInt()`: 다음 입력 존재 여부 확인
- 주의: `nextInt()` 뒤 `nextLine()` 호출 시 개행문자만 읽혀 빈 문자열 반환됨 → `nextLine()` 한 번 더 넣거나 처음부터 `nextLine()`+split 사용

### BufferedReader
- `readLine()`: 한 줄 전체를 문자열로 읽기(공백 포함), 없으면 null
- `close()`: 스트림 닫기
- 문자열만 읽으므로 숫자 변환엔 `Integer.parseInt()` 필요
- main에 `throws IOException` 필수

### StringTokenizer
- `new StringTokenizer(line)`: 공백 기준 분리 준비
- `nextToken()`: 토큰 하나씩 꺼내기
- `hasMoreTokens()`: 남은 토큰 존재 확인
- `countTokens()`: 남은 토큰 개수 확인

### 입출력 선택 기준
- 입력 적음 → Scanner
- 입력 많음/속도 중요 → BufferedReader + StringTokenizer
- 모르겠으면 → BufferedReader 기본값

### 출력
- `println(x)`: 값 출력 후 줄바꿈
- `print(x)`: 줄바꿈 없이 출력
- `printf("%d %.2f%n", ...)`: 형식 지정 출력
- `StringBuilder` + 마지막 일괄 출력: 반복 출력 시 속도 개선

### 형변환
- 문자열→정수: `Integer.parseInt(str)`
- 문자열→long: `Long.parseLong(str)`
- 정수→문자열: `String.valueOf(n)` / `n + ""`

### 입력 개수 모를 때
- `while ((line = br.readLine()) != null)`: EOF까지 읽기
- `while (sc.hasNextInt())`: Scanner로 값 존재 확인하며 반복
- n줄 반복 입력 시 StringTokenizer는 줄마다 새로 생성

### 문자열 파싱
- 한 줄 → 정수 배열: `Arrays.stream(br.readLine().split(" ")).mapToInt(Integer::parseInt).toArray()`
- 특수문자 split: `\\.`, `\\|` 등 이스케이프 필요
- 공백 여러 개: `split(" +")` 또는 `trim().split("\\s+")`
- 문자 하나 숫자 변환: `ch - '0'`

### 반복문

**for문**
```java
for (int i = 0; i < n; i++) {
    // i를 인덱스로 써야 할 때 (위치 비교, 역순 접근 등)
}
```
- 배열/리스트의 인덱스가 필요한 경우 사용 (두 요소 위치 비교, i번째와 i+1번째 비교 등)

**향상된 for문 (for-each)**
```java
for (int x : arr) {
    // 값만 필요할 때
}
```
- 인덱스 없이 값만 순회할 때 코드가 짧아져 실전에서 가장 많이 씀
- 인덱스가 필요한 순간(위치 비교, 값 변경 등)엔 사용 불가 → 기존 for문 사용
- 순회 중 컬렉션 자체를 수정(add/remove)하면 `ConcurrentModificationException` 발생 주의

### 기초 문법 체크리스트
- `static`만 확실히, `private`은 거의 안 씀
- `void` vs `return` 타입 명시
- 형변환은 `(int)`, `(double)` 캐스팅 정도만
- switch는 구식(`case X: break;`)만
- 메서드 오버로딩: 생략
- 삼항연산자: `조건 ? a : b`
- 레이블: `outer: for(...) { for(...) { break outer; } }`

## 2단계: 배열·문자열·자료구조

### 배열
- `.length`(배열) vs `.length()`(문자열) 혼동 주의
- `Arrays.copyOf(arr, n)`: 배열 복사

### 배열 ↔ 문자열 변환
- `str.toCharArray()`: 문자열 → 문자 배열
- `str.split(" ")`: 문자열 → 문자열 배열
- `Arrays.stream(str.split(" ")).mapToInt(Integer::parseInt).toArray()`: 문자열 → 정수 배열
- `new String(charArr)` / `String.valueOf(charArr)`: 문자 배열 → 문자열
- `Arrays.toString(arr)`: 정수 배열 → 문자열(디버깅용)
- `String.join(",", list)`: 리스트 → 구분자 문자열
- `Arrays.asList(arr)`: 문자열 배열 → 리스트(크기 고정)
- `Arrays.deepToString(arr2d)`: 2차원 배열 확인용

### String 메서드
- `length()`: 길이 확인
- `charAt(i)`: i번째 문자
- `substring(s, e)`: 부분 문자열(e 미포함)
- `split(regex)`: 구분자로 분리
- `equals(str)`: 값 비교 (`==` 금지)
- `equalsIgnoreCase(str)`: 대소문자 무시 비교
- `contains(str)`: 포함 여부
- `startsWith(str)` / `endsWith(str)`: 접두/접미 확인
- `replace(a, b)`: 치환
- `toUpperCase()` / `toLowerCase()`: 대소문자 통일
- `trim()`: 앞뒤 공백 제거
- `toCharArray()`: 문자 단위 처리
- `indexOf(str)`: 처음 등장 위치(없으면 -1)

### StringBuilder 메서드
- `append(x)`: 뒤에 이어붙이기
- `toString()`: String 변환
- `reverse()`: 문자열 뒤집기
- `insert(idx, x)`: 특정 위치 삽입
- `deleteCharAt(idx)`: 특정 위치 삭제
- `delete(s, e)`: 구간 삭제
- `setCharAt(idx, c)`: 특정 위치 문자 변경
- `charAt(idx)`: 문자 확인
- `length()`: 현재 길이
- `replace(s, e, str)`: 구간 교체
- `indexOf(str)`: 위치 찾기

### ArrayList 메서드
- `add(x)`: 추가
- `get(i)`: 조회
- `set(i, x)`: 변경
- `remove(i)` / `remove(Object)`: 삭제 (인덱스 vs 값 오토박싱 주의)
- `size()`: 크기
- `contains(x)`: 포함 여부
- `indexOf(x)`: 위치 찾기

### HashMap 메서드
- `put(key, value)`: 저장/갱신
- `get(key)`: 조회(없으면 null)
- `getOrDefault(key, 기본값)`: 빈도수 계산 필수
- `containsKey(key)`: 키 존재 확인
- `remove(key)`: 삭제
- `keySet()`: 키 순회
- `entrySet()`: 키+값 순회
- 빈도수 패턴: `map.put(key, map.getOrDefault(key, 0) + 1)`

### HashSet 메서드
- `add(x)`: 추가(중복 무시)
- `contains(x)`: 존재 확인
- `remove(x)`: 삭제
- `size()`: 개수

### Stack / Queue
- Stack: `push(x)`, `pop()`, `peek()` — 괄호 매칭 등
- Queue(LinkedList): `offer(x)`, `poll()`, `peek()` — BFS 필수

## 3단계: 정렬 + 기본 알고리즘 패턴

### 정렬
- `Arrays.sort(arr)`: 배열 오름차순(기본형 내림차순 불가 → Integer[] 박싱 필요)
- `Collections.sort(list, (a,b) -> a-b)`: 오름차순
- `Collections.sort(list, (a,b) -> b-a)`: 내림차순

### 알고리즘 패턴
- 완전탐색: N≤10~15, 모든 경우 확인
- 해시: 빈도수/매칭 여부
- 투 포인터: 정렬된 배열에서 두 지점 좁히기
- 슬라이딩 윈도우: 연속 구간 합/최댓값
- 누적합: 구간 합 반복 계산
- 이진 탐색: 정렬된 데이터 탐색, 파라메트릭 서치

---

## 4단계: 심화 알고리즘 (얕고 넓게)

- 재귀: 함수가 자신을 재호출 (DFS·DP 기반)
- DFS: 한 방향 끝까지 탐색 후 백트래킹 — 경로/조합 전체 탐색
- BFS: 가까운 것부터 순서대로 탐색 — 최단 거리
- 백트래킹: DFS 중 조건 안 맞으면 되돌아감 — 순열/조합
- 그리디: 매 순간 최선 선택 — 정렬 후 순차 처리
- DP: 계산 결과 저장 후 재사용 — 피보나치류 (1차원까지만)

---

## 5단계: 문제 풀이 프로세스

1. 입출력 형식 확인 (매개변수 vs 직접 입력)
2. 제한사항으로 시간복잡도 역산 (N≤1000→O(N²), N≤100000→O(N log N) 이하)
3. 예제 손으로 트레이싱
4. 자료구조 결정
5. 코드 작성 후 눈으로 트레이싱
6. 예외 케이스 점검(빈 입력, 길이 1, 중복값, 경계값)

---

## 6단계: 손코딩 실전 대비

- import 목록/클래스명/괄호 짝 정확히: `java.util.*`, `java.io.*` 암기
- 들여쓰기로 중괄호 짝 검증
- 변수명 짧고 일관되게
- `=`/`==`, `length`/`length()` 혼동 스스로 점검
- 시간 부족 시 논리 우선, 문법은 나중에 다듬기

## 7단계: 프로그래머스 레벨 0~2 대비

- 레벨 0: 문법 연습 (조건문/반복문/배열/문자열 기본) — 1~2단계 개념이면 충분
- 레벨 1: 기초 구현 (문자열 처리, 기본 해시/정렬) — 구현 정확도가 관건
- 레벨 2: 실전 패턴 (해시, 스택/큐, 완전탐색, 그리디, 기본 DFS/BFS) — 기업 코테 60~70% 비중, 벼락치기 목표 지점

**학습 순서**: 레벨 0 빠르게 전부 → 레벨 1로 메서드 숙련도 확인 → 레벨 2로 패턴 매칭 연습 → 여유 있으면 손코딩으로 재풀이
